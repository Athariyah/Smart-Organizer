# 💻 IT-CRM & Task Manager (Российский аналог Calendly / YClients)

Узконаправленная платформа для управления задачами, клиентами и финансами, разработанная специально для российских IT-специалистов, фрилансеров (самозанятых) и небольших digital-агентств.

Это не просто таск-трекер. Это полноценная замена зарубежным сервисам (таким как Calendly, YClients, Trello, Jira) с адаптацией под российские реалии бизнеса и уникальными инструментами для разработчиков.

## 🎯 Для кого этот сервис?
- **IT-фрилансеры и Самозанятые** (программисты, дизайнеры, DevOps, QA).
- **IT-аутсорсеры**, ведущие несколько проектов одновременно.
- **Небольшие студии разработки**, которым нужен единый хаб для задач, счетов и расписания без лишнего корпоративного мусора.

## 🚀 Ключевые возможности

### 1. 📅 Продвинутый Календарь и Букинг (Аналог Calendly)
- Управление расписанием встреч, созвонов (синков) и дедлайнов.
- Быстрый обзор загруженности и планирование спринтов.

### 2. 📋 Канбан-доска и Управление Задачами (Task Manager)
- Классическая Канбан-доска для отслеживания статусов задач (К выполнению, В работе, Ревью, Готово).
- Поддержка тегов, дедлайнов и удобной фильтрации.
- **Синхронизация с GitHub**: Прямой импорт открытых Issues из ваших репозиториев (в формате `owner/repo`) прямо на доску задач в один клик.

### 3. 👥 CRM-система (Управление клиентами)
- Ведение базы клиентов, сохранение контактных данных (Telegram, Email).
- История взаимодействия, статусы и привязанные к заказчикам проекты и счета.

### 4. 💰 Финансы, Счета и Налоги (Адаптация под РФ)
- **Генерация счетов и актов**: Автоматическое создание документов для заказчиков с возможностью выгрузки/шаринга.
- **Калькулятор НПД (Налог на профессиональный доход)**: Встроенный, интуитивный расчет налогов для самозанятых (4% при работе с физлицами, 6% при работе с юрлицами).
- Отслеживание статуса оплат (Оплачено / Ожидает оплаты / Просрочено).

### 5. 🛠 Инструменты Разработчика (IT Tools / DevTools)
Встроенный набор мощных утилит, позволяющий решать рутинные задачи не покидая CRM:
- **Regex Tester** (Тестирование регулярных выражений с подсветкой групп)
- **JSON Formatter & Minifier** (Форматирование и сжатие JSON)
- **Unix Timestamp Converter** (Перевод дат в Timestamp и обратно)
- **JWT Decoder** (Безопасная локальная расшифровка токенов)
- **Base64 & URL Encoder/Decoder**
- **UUID Generator** (Массовая генерация до 100 ключей)
- **SHA-256 Hash Generator**
- **Color Converter** (Быстрый перевод HEX ⇄ RGB)

### 6. 📊 Аналитика и Отчеты
- Визуальные дашборды (доходы, продуктивность, закрытые задачи).
- Генерация подробных отчетов по периодам для анализа эффективности работы.

### 7. ⚡ Продуктивность и Hotkeys (Vim-style)
- Глубокая поддержка шорткатов для навигации без мыши (Power-user friendly).
- Нажмите `G`, чтобы вызвать панель **HUD**, и затем соответствующую клавишу для мгновенного перехода:
  - `G` + `D` — Обзор (Dashboard)
  - `G` + `T` — Задачи
  - `G` + `I` — Счета
  - `G` + `C` — Клиенты
  - `G` + `K` — Календарь
  - `G` + `X` — Калькулятор НПД
  - `G` + `E` — Инструменты разработчика (DevTools)
  - `G` + `A` — Аналитика

## 🛠 Технический стек
- **Frontend**: React 18, TypeScript, Vite
- **Стилизация**: Tailwind CSS (с поддержкой Dark Mode)
- **Анимации**: Framer Motion
- **Иконки**: Lucide React
- **Архитектура**: Client-side (SPA)

## 📦 Установка и запуск (для разработчиков)

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
3. Для сборки в production:
   ```bash
   npm run build
   ```
